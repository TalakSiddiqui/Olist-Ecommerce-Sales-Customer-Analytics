# Olist E-Commerce Sales & Customer Analytics

## 📌 Project Overview

<img width="780" height="546" alt="image" src="https://github.com/user-attachments/assets/63626280-893e-46ac-b3ae-679f36290dfe" />

This project analyses the Olist e-commerce dataset to understand sales performance, customer behaviour, order trends, product performance, and regional sales patterns.

The project combines SQL, Excel, Power Query, and Power BI to transform raw e-commerce data into meaningful business insights and an interactive dashboard.

## 🎯 Business Objectives

- Analyse overall sales and order performance
- Understand customer purchasing behaviour
- Identify top-performing product categories
- Analyse sales performance by customer state
- Track monthly sales and order trends
- Analyse order status and delivery performance
- Identify customers with multiple orders
- Calculate key business KPIs such as Sales, Orders, Customers and AOV

## 🛠️ Tools & Technologies

- **SQL (MySQL)** – Data analysis and business queries
- **Microsoft Excel** – Data cleaning and initial analysis
- **Power Query** – Data transformation
- **Power BI** – Interactive dashboard and data visualization
- **DAX** – KPI calculations and measures

## 📊 Dataset

The project uses the Olist Brazilian e-commerce dataset containing information about:

- Customers
- Orders
- Order Items
- Products

The analysis covers approximately:

- **99K orders**
- **96K customers**
- **13.59M in product sales**

## 🔍 SQL Analysis

SQL was used to answer business questions such as:

- What is the total number of orders?
- Which customers have placed multiple orders?
- What are the top-performing customer states?
- What is the total sales generated by each customer?
- Which products/items have prices above the average?
- What is the distribution of customers across states?
- Which customers have no orders?
- How are orders distributed by status?

SQL techniques used:

- SELECT
- WHERE
- JOIN
- LEFT JOIN
- RIGHT JOIN
- GROUP BY
- HAVING
- CASE WHEN
- Subqueries
- CTEs
- Aggregate Functions

## 💡 Key Insights

- The business generated approximately **13.59M in product sales**.
- The dataset contains approximately **99K orders** and **96K customers**.
- The overall delivery rate is approximately **97%**.
- Average Order Value is approximately **120.65**.
- Sales performance varies significantly across product categories and customer states.
- A relatively small number of product categories and regions contribute a significant share of overall sales.
